# Universal Dependencies English-EWT (extrait)

Extrait de l'UD English Web Treebank (Silveira et al., 2014 ; Universal Dependencies) : pour chaque phrase, une ligne « mot<TAB>UPOS » par token (les lignes de mots multiples et de nœuds vides sont ignorées), phrases séparées par une ligne vide. Fichiers : `train.tsv` (12 544 phrases, 204 578 mots), `dev.tsv` (2 001 phrases), `test.tsv` (2 077 phrases).

Source : https://github.com/UniversalDependencies/UD_English-EWT (fichiers `en_ewt-ud-{train,dev,test}.conllu`). Licence : CC BY-SA 4.0 (voir le dépôt d'origine pour les attributions du texte). Utilisé pour l'amendement 35 du protocole (étiquetage grammatical, de gauche à droite).
